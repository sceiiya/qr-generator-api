🎯 QR Code API

A serverless API service for generating QR codes with embedded data

Powered by external QR code service for reliability

Version: 1.0.0

GET/api/qr-generate

Generate QR code image directly from URL parameters

GET /api/qr-generate?type=json&provider=GCASH&account_number=9873297&account_name=gladmad%20wiver
Parameters:
• type (required): "json" or "url"
• provider (required): Payment provider name
• account_number (required): Account number
• account_name (required): Account holder name

POST/api/qr-generate

Generate QR code with JSON data embedded

POST /api/qr-generate Content-Type: application/json { "provider": "GCASH", "account_number": "9873297", "account_name": "gladmad wiver" }

POST/api/qr-generate-url

Generate QR code with URL containing query parameters

POST /api/qr-generate-url Content-Type: application/json { "provider": "GCASH", "account_number": "9873297", "account_name": "gladmad wiver" }
